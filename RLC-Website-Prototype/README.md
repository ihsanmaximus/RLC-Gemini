# Rifdaira Learning Center (RLC) — Website Prototype

Prototipe website interaktif dengan akurasi tata letak dan visual (*pixel-accurate*) berdasarkan desain acuan resmi Rifdaira Learning Center.

## Cara Menjalankan

Website ini menggunakan arsitektur murni web modern (*HTML5, CSS3, Vanilla JS*) tanpa dependensi *node_modules* atau server backend.

1. Simpan seluruh file sesuai bagan struktur direktori di atas.
2. Buka berkas `index.html` langsung di browser modern Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) atau gunakan ekstensi **Live Server** di VS Code.
3. Seluruh interaktivitas tombol, dropdown, form modal, dan widget verifikasi sertifikat sudah langsung aktif.
